## 🧑‍💻 Sobre mí

Tengo 22 años y curso el segundo año de la **Tecnicatura Universitaria en Programación** en la **UTN FRC** (Córdoba), que termino en 2026. Me gusta tomar desafíos que tengan que ver con el desarrollo tecnológico.

Me especializo en **backend con Java y Spring Boot**: creo APIs REST y trabajo con bases de datos relacionales y no relacionales. Hoy mi foco está en el recorrido completo de una aplicación: Java con Spring Boot del lado del servidor, **Angular** en la interfaz, y **Docker** junto con herramientas de **CI/CD** para automatizar cómo se construye y se despliega. Trabajo con metodologías ágiles (**Scrum**) y apunto a soluciones limpias y escalables.

## 🖥️ Mi portfolio

[**Joaquín Developer System**](https://welcomehommiestomyportfolio.netlify.app/) es mi portfolio, pensado como una interfaz de software de los años 2003–2005 y hecho con **Angular 22** (componentes standalone, signals y SCSS, sin framework de UI). Tiene:

- Navegación por módulos (perfil, base de proyectos, componentes instalados, bitácora, terminal de contacto y red externa)
- Interfaz bilingüe **ES / EN**
- Accesibilidad cuidada: teclado, foco visible, contraste y `prefers-reduced-motion`
- Código abierto: [My-Portfolio-JC](https://github.com/CortezJoaquinDev1913/My-Portfolio-JC)
